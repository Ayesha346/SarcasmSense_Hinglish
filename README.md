This project focuses on sarcasm detection in Hinglish (Hindi-English code-mixed) social media text using both traditional machine learning models and transformer-based deep learning techniques. A custom dataset of 5000 labeled comments (sarcastic and non-sarcastic) was created to address the challenges of informal language, slang, and non-standard grammar. The implementation includes models such as Logistic Regression, SVM, and Random Forest using TF-IDF features, along with a fine-tuned multilingual BERT model for contextual understanding. The performance of all models is evaluated using accuracy, precision, recall, and F1-score, and visualized through graphs for comparison. The project demonstrates the effectiveness of advanced NLP techniques in handling code-mixed languages and highlights the importance of contextual modeling for sarcasm detection in real-world Indian social media data.
